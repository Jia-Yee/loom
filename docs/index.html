项目简介

Loom 是一个可扩展的自动化机器学习框架。核心设计原则：新增模型或数据集只需新建文件 + 加一行 import，不改核心代码。

框架支持回归与分类任务、多模型对比选优、超参随机搜索、LLM 智能分析（DeepSeek / Ollama），以及 Web 控制台实时可视化。

设计哲学：注册机制驱动，所有扩展点通过装饰器接入。core/ 目录在扩展时永远不需要修改。

功能特性

🔧 注册机制

@register_model / @register_dataset 装饰器，新增项零改 core/
registry.py

🔀 多模型调度

run() 接受 str 或 list，统一返回结构，自动选优
runner.py

🤖 LLM 分析

DeepSeek / Ollama 双 provider，训练前分析 + 训练后解读
llm_analyzer.py

🔍 超参搜索

RandomizedSearchCV，param_space() 定义搜索空间
runner.py

📊 分类支持

回归/分类双模式，accuracy/f1/auc 指标，类型校验
runner.py

💾 结果持久化

SQLite 三表存储，--history 查询历史实验
store.py

🌐 Web 控制台

SSE 实时进度、CSV 上传、画布拖动、日志输出
server.py + web/

📦 零改重命名

相对导入 + 动态包名，拷贝改目录名直接能跑
core/__init__.py

模型列表

所有模型继承 BaseModel，通过 @register_model 注册。新增模型只需在 models/ 下新建文件。

注册名类名任务类型底层实现参数空间说明
linear_regression LinearRegressionModel regression sklearn LinearRegression fit_intercept 线性回归，最小二乘拟合
random_forest RandomForestModel regression sklearn RandomForestRegressor n_estimators, max_depth 随机森林回归，集成学习
ridge RidgeModel regression sklearn Ridge alpha Ridge 回归，L2 正则化
logistic_regression LogisticRegressionModel classification sklearn LogisticRegression C, solver 逻辑回归，二分类/多分类

BaseModel 接口

class BaseModel(ABC):
    task_type: str = "regression"  # 或 "classification"

    def fit(self, X: np.ndarray, y: np.ndarray) -> None: ...
    def predict(self, X: np.ndarray) -> np.ndarray: ...
    def get_params(self) -> dict: ...
    def param_space(self) -> dict: ...  # 超参搜索空间，可返回空

CSV 上传 用户上传 regression / classification — — CSV 列名自动解析

BaseDataset 接口

class BaseDataset(ABC):
    task_type: str = "regression"

    def load(self) -> tuple[np.ndarray, np.ndarray]: ...  # 返回 (X, y)
    def feature_names(self) -> list[str]: ...
    def summary(self) -> dict: ...  # 自动生成，子类可覆盖

CSV 上传流程

  1. Web 控制台左侧点击「上传 CSV」
  2. 选择文件 → 后端解析列名和前 5 行预览
  3. 选择目标列（target_column）和任务类型
  4. 确认后自动注册为数据集，下拉框立即可选

步骤说明

步骤说明状态SSE 事件
init校验模型与数据集 task_type 一致性running → success/failedstep: init
dataset加载数据集，生成摘要（样本量、特征统计）running → successstep: dataset
llm_init初始化 LLM（DeepSeek/Ollama），未配置则跳过success/skippedstep: llm_init
llm_pre训练前 LLM 分析（仅一次，所有模型共享）running → success/skippedstep: llm_pre
split划分训练/测试集running → successstep: split
train模型训练（每个模型独立）running → successstep: train
search超参搜索（search=True 时触发）running → success/failedstep: search
metric计算评估指标（MSE/R² 或 accuracy/f1/auc）success含在 train 事件中
select_best多模型对比选优（select_best=True 时）successstep: select_best
llm_post训练后 LLM 结果解读（按模型）running → success/skippedstep: llm_post
done流水线完成，写入 nodes.json + SQLitesuccesstype: done

扩展指南

添加新模型

第 1 步：在 models/ 下新建文件

# models/my_model.py
import numpy as np
from ..core.base import BaseModel
from ..core.registry import register_model

@register_model("my_model")
class MyModel(BaseModel):
    task_type = "regression"

    def __init__(self, alpha=1.0):
        self._model = SomeSklearnModel(alpha=alpha)

    def fit(self, X, y):
        self._model.fit(X, y)

    def predict(self, X):
        return self._model.predict(X)

    def get_params(self):
        return {"alpha": self._model.alpha}

    def param_space(self):
        return {"alpha": [0.01, 0.1, 1.0, 10.0]}

第 2 步：在 models/__init__.py 加一行

from . import my_model  # noqa: F401
完成。run("my_model", "diabetes") 即可使用，core/ 无需改动。

API 接口

Web 服务器（python server.py）提供以下 REST API：

方法路径说明
GET/api/models列出已注册模型，可选 ?task_type=regression
GET/api/datasets列出已注册数据集
POST/api/run_stream运行流水线（SSE 流式返回进度）
POST/api/upload_csv上传 CSV 文件，返回列名和预览
GET/api/history查询历史运行记录
GET/api/run/<run_id>查询单次运行详情
GET/api/config查看当前 LLM 配置状态

SSE 运行示例

POST /api/run_stream
Content-Type: application/json

{
  "model_names": ["linear_regression", "random_forest"],
  "dataset_name": "diabetes",
  "select_best": true,
  "test_size": 0.2,
  "seed": 42

→ SSE 响应流：

data: {"type": "step", "step": "dataset", "status": "success", ...}

data: {"type": "done", "run_id": "...", "nodes": [...], "edges": [...]}

LLM 配置

通过环境变量或 .env 文件配置：

变量说明默认
AUTOML_LLM_PROVIDERdeepseek 或 ollama无（跳过 LLM）
AUTOML_LLM_API_KEYDeepSeek 需要；Ollama 填占位符无
AUTOML_LLM_BASE_URL覆盖默认端点按 provider
AUTOML_LLM_MODEL模型名按 provider
AUTOML_LLM_TIMEOUT超时秒数30

Ollama 配置示例

# .env
AUTOML_LLM_PROVIDER=ollama
AUTOML_LLM_API_KEY=placeholder
AUTOML_LLM_MODEL=qwen3.5:4b

DeepSeek 配置示例

# .env
AUTOML_LLM_PROVIDER=deepseek
AUTOML_LLM_API_KEY=sk-your-key-here
AUTOML_LLM_MODEL=deepseek-chat
容错保证：LLM 任何失败（网络超时、密钥缺失、模型不存在）不影响训练评估主流程，对应节点标记 status: "skipped"。
